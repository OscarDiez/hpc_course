## Exam review priorities

- **Correctness before performance:** races, reductions, MPI collective consistency, barriers.
- **Explain speedup:** baseline, parallel overhead, strong vs weak scaling.
- **Understand data movement:** compute vs memory vs network bottlenecks.
- **Choose tools:** threads inside nodes, MPI among nodes, GPU for suitable kernels, Slurm allocations.
- **Reproducibility:** environment, build flags, input data, seed and measurable outputs.
