# M1.S2 - Evolution of supercomputing and the modern HPC landscape

Interactive notebook for Module 1, Session 2.

The notebook reinforces the main ideas of the session through short experiments and guided interpretation:

- broad evolution from mechanical/electronic computing to exascale;
- vector and SIMD thinking;
- power wall and memory wall;
- distributed systems and communication;
- commodity clusters;
- hardware/software co-evolution;
- FLOPS, HPL and time-to-solution;
- modern heterogeneous HPC;
- comparison of modern system architectures;
- safe inspection of the SciTech teaching cluster.

Teaching pattern:

```text
PREDICT -> RUN -> OBSERVE -> EXPLAIN
```
