## Classroom method

**PREDICT → RUN → OBSERVE → EXPLAIN**

The notebook covers independence, task/data decomposition, dependencies, synchronization, granularity, load balancing, Slurm placement and a short final challenge.

The short Python timing examples are conceptual demonstrations, not hardware benchmarks. Slurm-specific cells fail gracefully if Slurm is not available.
