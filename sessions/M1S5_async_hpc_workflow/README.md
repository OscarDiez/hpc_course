# M1.S5 - Asynchronous Guided HPC Workflow

## Part 1 - Guided lab

This 90-minute guided notebook consolidates Module 1 around one complete CPU workflow on the SciTech cluster.

It connects:

- M1.S1 fundamentals and performance goals;
- M1.S2 evolution and moving bottlenecks;
- M1.S3 architecture and hierarchy;
- M1.S4 Slurm resource management and performance metrics.

Students:

- inspect the real SciTech environment;
- compile a small numerical C application;
- perform a correctness sanity check;
- submit and monitor a real Slurm job;
- inspect accounting evidence with `sacct`;
- change one CPU resource request;
- compare runtime, speedup and allocation efficiency;
- interpret the run through architecture and scheduling concepts;
- hand off to Practice 1 in Blackboard.

Teaching pattern:

```text
PREDICT -> RUN -> OBSERVE -> EXPLAIN
```
